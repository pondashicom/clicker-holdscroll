# Clicker HoldScroll

Windows の左右矢印キーを、押している時間で使い分ける常駐トレイアプリです。

- 短押し: `←` / `→` を通常どおり1回入力
- `←` 長押し: マウスホイール相当で上へ連続スクロール
- `→` 長押し: マウスホイール相当で下へ連続スクロール
- PowerPointノートモード: 長押しを、起動中の発表者ツールのノートだけへ送信

## 公開範囲とプライバシー

このリポジトリはソースコードを公開します。生成物や署名済みバイナリは含めていません。利用する場合はソースからビルドしてください。

Clicker HoldScroll は Windows の低レベルキーボードフックでシステム全体のキーイベントを受け取り、左右矢印キーだけを判定します。キー入力の内容を保存・送信する機能はありません。

## 使い方

1. `scripts\publish.ps1` を実行して `dist\Clicker-HoldScroll.exe` を生成します。
2. `dist\Clicker-HoldScroll.exe` を起動します。
3. 通知領域に常駐します。メインウィンドウはありません。
4. 通知領域アイコンの右クリックで、長押し判定、スクロール速度、PowerPointノートモードを変更できます。
5. アイコンのダブルクリックで一時的に有効／無効を切り替えられます。
6. 緊急時は `Ctrl+Shift+F12` で入力変換を即時停止できます。
7. 終了は右クリックメニューの「終了」です。

初回起動時は安全のため無効状態です。通知領域アイコンをダブルクリックして有効にしてください。

設定は `%LOCALAPPDATA%\Clicker-HoldScroll\settings.json` に保存されます。
運用ログは `%LOCALAPPDATA%\Clicker-HoldScroll\logs\clicker-holdscroll.log` に保存されます。キー入力内容は記録しません。

### PowerPointノートモード

1. PowerPointでスライドショーを開始し、発表者ツールを表示します。
2. 通知領域メニューで「PowerPointノートモード」を有効にします。
3. Clicker HoldScrollを有効にします。
4. `←` 長押しでノートを上へ、`→` 長押しでノートを下へスクロールします。

発表者ツールは `PodiumParent` 配下の表示面を使って識別します。長押し時はノート領域の座標を指定してPowerPointへ直接ホイールメッセージを送り、キーボードフォーカスとマウスカーソルは移動しません。発表者ツールを見つけられない場合は通常ホイールへフォールバックせず、他の画面を誤スクロールしません。

## 安全機能

- キーアップイベントで連続スクロールを即時停止
- キーアップを取り逃しても既定30秒で強制停止し、次のキーアップまで再始動しない
- 画面ロック、RDP切断、スリープ時に自動無効化
- 入力再送またはキーボードフック障害時に自動無効化してログへ記録
- PowerPointノートモードで発表者ツールが見つからない場合、通常画面へホイールを誤送信しない
- キーボードフックを専用スレッドで処理し、30秒ごとに再登録
- 修飾キーが押された場合は変換を安全に中断し、意図しないショートカット化を防止
- 設定は一時ファイルから置換し、直前の設定を `.bak` に保存
- 設定破損時は破損ファイルを退避し、無効状態で起動

## 仕様上の注意

- 短押しの矢印入力は、キーを離した瞬間に発生します。長押しかどうかを先に判定するため、この遅延は必要です。
- Ctrl / Shift / Alt / Windows キーと同時に押した左右キーは安全のため横取りしません。
- 管理者権限で動くアプリ上では、通常権限の Clicker HoldScroll が入力を横取りできない場合があります。入力再送に失敗した場合は自動的に無効化します。
- PowerPointノートモードは、Windows版PowerPointの発表者ツールを対象にしています。通常編集画面のノートペインやPowerPoint以外のノート画面は対象外です。
- リモートデスクトップ、ゲーム、独自入力処理を使うアプリでは期待どおりにならない場合があります。
- 単一EXEは起動時に.NETのネイティブ部分を `%TEMP%\.net` へ展開します。端末制限がある環境では事前確認してください。

## ソースからビルド

.NET 8 SDK を使います。

```powershell
dotnet build .\ArrowWheel.sln -c Release
dotnet run --project .\tests\ArrowWheel.StateTests\ArrowWheel.StateTests.csproj -c Release
```

検証、テスト、単一EXEの発行をまとめて行う場合:

```powershell
.\scripts\publish.ps1
```
